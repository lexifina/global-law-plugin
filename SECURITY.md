# Security

Report a vulnerability in this plugin or in the hosted Global law MCP server privately:

- on GitHub: **Security → Report a vulnerability** on this repository, or
- by email: global-law@lexifina.com

Please do not open a public issue for it. Say what you found and how to reproduce it; we will reply within
five working days.

The plugin holds no code that runs on your machine beyond the test scripts: it is skill text and the address of
a read-only server that needs no account or key.
